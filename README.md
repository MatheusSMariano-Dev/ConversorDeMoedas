# 💱 Conversor de Moedas - Java

Projeto desenvolvido como desafio da Alura.

## Funcionalidades
- Conversão de moedas em tempo real
- Menu interativo via console
- Consumo da Exchange Rate API
- Desserialização JSON com GSON

## Como executar
1. Abra no IntelliJ
2. Adicione a dependência GSON
3. Execute a classe Main
